# HR Hub by Mia (portfolio preview)

Browser-based document, design and scheduling tools. Nothing is uploaded or stored.

## Free preview
Each visitor gets 1 free download per tool. After that, downloads show a pop-up asking them to contact miabr.marie@gmail.com.
The count is kept in the visitor's own browser (no database), so it is a deterrent rather than a hard lock.

## Owner access (you)
- Unlock unlimited use in your browser: open any page with `?unlock=mia-unlock-2026`
- Reset your browser back to visitor mode: `?relock=mia-unlock-2026`
- To change the code, edit OWNER_CODE near the top of the "Portfolio preview" script in each page (search for `OWNER_CODE`).

## Publish
Upload all .html files to a GitHub repository and turn on GitHub Pages (Settings > Pages > Deploy from a branch > main / root).
